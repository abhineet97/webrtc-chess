# WebRTC Chess

Chess moves travelling through WebRTC.

## Build Instructions

Install [Node.js](https://nodejs.org/en/) and then:

```sh
$ npm install
$ npm run build
```

Start the app:

```sh
$ npm start
```

and then navigate to [http://localhost:8080](http://localhost:8080).
